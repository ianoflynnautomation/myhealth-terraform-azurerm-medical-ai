# workload-identities

Composition wrapper over the AVM user-assigned managed identity module,
applying it with `for_each` so the whole set of workload identities is
declared as one map.

Each entry can carry federated identity credentials and Azure role
assignments. The module returns `client_ids` and `principal_ids` maps that
the root module wires into Key Vault, storage, Document Intelligence,
Search, SQL, Cosmos, and Foundry.

The identities themselves are documented in
[identity.md](../../docs/architecture/identity.md).
